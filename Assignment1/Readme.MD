# ☕ UPI Payment Flow — VibeCoding Assignment A

A simple web app that simulates a ₹1 payment using UPI deep links.

---

## 🎯 Features
- Generates a UPI deep link.
- Opens any installed UPI app (GPay, PhonePe, Paytm).
- Manual confirmation with transaction ID.

---

## 🧰 Tech Stack
HTML • CSS • JavaScript  
Hosted on Vercel

---

## 🧠 How It Works
1. Click “Pay via UPI”
2. Your UPI app opens with ₹1 payment details pre-filled
3. Enter a transaction ID to simulate payment confirmation
