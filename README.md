## 💸 Assignment A — UPI Payment Flow

📂 **Code Folder:** [assignment-a](./assignment-a)  
🔗 **Live Demo:** https://taska-sooty.vercel.app/

**Description:**  
A simple webpage demonstrating UPI deep linking. Clicking “Pay via UPI” opens any installed UPI app (like GPay, PhonePe, or Paytm) pre-filled with ₹1 as a test payment.

**How to Test:**
1. Open the https://taska-sooty.vercel.app/
2. Click **Pay via UPI**
3. Select a UPI app on your device
4. You’ll be redirected with a ₹1 test payment

📂 **Code Folder:** [assignment-b](./assignment-b)  
🔗 **Live Demo:** https://taska-6q5q.vercel.app/
